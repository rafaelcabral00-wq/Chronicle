# Rule Set Documentation

Rule Set documentation contains extraction evidence, prototype records, validation findings, and package authoring references.

## Reading Order

1. [RFC-0027: Rule Set Package Architecture](../rfcs/RFC-0027-Rule-Set-Package-Architecture.md)
2. [SPEC-0001: Rule Set Package Artifact Model and Extraction Contract](../specs/SPEC-0001-rule-set-package-artifact-model-and-extraction-contract.md)
3. Extraction records under `docs/extraction/`
4. Rule Set documentation and review artifacts under this directory

## Authority Rules

- A documentation prototype is review and authoring evidence.
- A Rule Set package source directory is a separate materialization role.
- A packaged artifact is a versioned build output.
- An installed artifact exists only after an installation transition.

Repository presence alone does not publish, install, enable, activate, or bind a Rule Set to a Campaign.

## Status and Supersession

Check each Rule Set document's status and evidence freshness.

Unresolved source decisions, stale evidence, failed localization validation, failed security validation, missing provenance, or incomplete reconciliation block promotion for the affected declared scope.
