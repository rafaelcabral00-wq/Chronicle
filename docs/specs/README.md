# Specifications

Specifications define detailed normative contracts.

## Reading Order

1. [SPEC-0001: Rule Set Package Artifact Model and Extraction Contract](SPEC-0001-rule-set-package-artifact-model-and-extraction-contract.md)

## Authority Rules

- SPEC-0001 defines Rule Set package artifact families, lifecycle, materialization role mapping, extraction workflow, validation evidence, and publication boundaries.
- RFC-0027 provides the higher-level Rule Set package architecture.
- ADR-0043 controls repository topology and project paths.

## Status and Supersession

Check `status`, `version`, `depends_on`, and validation metadata before treating a specification as implementation authority.

Documentation prototypes remain evidence only unless transformed through the accepted materialization contract.
